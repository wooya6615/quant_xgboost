# 사전등록: triple-barrier pt_sl 재검증 (2026-08)

이전 [배포 부적합] 판정의 근거는 pt_sl 축 PBO 95.6% -- 채택했던 (2,1)이
in-sample 최고빈도 순위 4/5위였고, 폐기한 (1,1)이 가장 자주 1등이었던
"사후 선택 문제"였음. 이번엔 이를 원천 차단하기 위해 pt_sl을 결과 확인 전

## 근거 (결과 비의존적)
- threshold=0.65는 예측 확신도이지 캘리브레이션된 실제 승률이 아님

  낮아도(예: 40%대) 기댓값이 양수로 유지되는 여유 확보 목적
- 일반적 리스크관리 원칙에서 도출, 이 프로젝트의 어떤 백테스트 결과도 참조하지 않음
