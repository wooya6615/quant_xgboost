# AI 퀀트 트레이딩 프로젝트 종합 보고서

**작성일 기준 프로젝트 범위**: 가격 단독 baseline + alternative data 7종 (수급/공매도/밸류에이션/환율/외국인보유율/DART공시빈도/DART대량보유상황보고)

**핵심 질문**: 표준 가격/거래량 기술지표를 넘어서는 대안 데이터가 XGBoost 방향성 예측 모델에 실질적인 edge를 제공하는가?

---

## 1. 방법론 요약

- **가격 feature (BASE)**: 모멘텀·변동성·거래량·상대강도 13개
- **검증 체계**: Walk-Forward + Embargo(라벨 겹침 방지), 5개 시드(42/1/7/123/2024) 반복, horizon 스윕(1/3/5/10/20일)
- **평가 지표**: AUC, base_rate 대비 우위(`vs_base_rate`)를 함께 봄 (둘이 어긋나면 노이즈로 판단)
- **판정 기준**: 시드 간 표준편차가 평균의 50%를 넘으면 노이즈로 간주. `COMBINED-BASE` AUC 차이의 방향이 5개 시드 모두 일치하는지 확인
- **실전 검증**: 거래비용(왕복 0.2%) 반영 백테스트로 Buy & Hold와 비교
- **국면 집중도 검증**: 백테스트 수익을 연도별로 분해해서 특정 연도 하나에 몰려있지 않은지 확인 (log-return 기여도 50% 초과 시 "국면 의존적"으로 판정)

## 4. 프로젝트 전체를 관통하는 핵심 교훈

### 4-1) AUC 개선과 실전 손익 개선은 별개 문제이며, 실패 유형이 최소 두 가지로 나뉨

1. **국면 집중형**: 특정 연도 하나의 우연에 기댄 결과. 밸류에이션(삼성전자 2025년, 모트렉스 2020년), FX(로템 2025년, 대한제강 2018년)에서 확인. 해당 연도를 제외하면 결론이 뒤집히거나 착시였음이 드러남. 비지도 국면 클러스터링(quant_unsupervised, 8절 참고)으로 모트렉스 2020년(7.76배)과 한전기술 2021년(5.08배)이 실제로 통계적 이례 국면이었음을 라벨 없는 독립적 방법론으로 재확인함 -- "우연"이라는 판단이 연도별 손익 비중 집계뿐 아니라 시장 상태 자체의 통계적 이례성으로도 뒷받침됨.
2. **구조적 저하형**: 여러 해에 걸쳐 일관되게 원래 이익이던 구간을 손실로 뒤집는 경우. 외국인 보유율 실험에서 처음 확인. 특정 연도 제외로는 해결되지 않음.

두 유형은 원인과 대응이 다르므로, 연도별 분해 시 최대 기여 연도 비중뿐 아니라 **BASE 대비 COMBINED의 손실/이익 연도 개수 변화**도 함께 봐야 함.

### 4-2) "COMBINED가 항상 최선"이라는 가정은 틀렸다

대한제강 h=20 사례에서 국면 조정 후 BASE 단독(204.9%, 최대기여 37.9%)이 COMBINED(146.7%, 최대기여 44.6%)보다 수익률·견고성 모두 우수했음. Ablation의 AUC 순위와 실전 백테스트의 견고성 순위가 다를 수 있다는 뜻이며, **최종 모델은 종목마다 다른 feature 조합이 최적일 수 있음**을 시사.

### 4-3) 유동성 가설은 AUC 수준에서는 대체로 지지되나, 실전 손익까지는 보장하지 않음

수급/밸류에이션/FX/외국인보유율 모두 "저유동성 종목에서 AUC 신호가 강함"이라는 패턴을 반복 확인했으나, 저유동성 4종목 중 실전 백테스트가 Buy&Hold를 이긴 건 절반 수준(로템/한전기술/대한제강 3개, 모트렉스는 실패)에 그침.

### 4-4) 데이터 정합성 검증은 결론을 뒤집을 수 있다

대한제강 종목코드 오류(001430 세아베스틸지주 vs 084010 진짜 대한제강)로 인해 "이 전략이 이 종목엔 구조적으로 안 맞는다"는 결론이 완전히 반대로 뒤집힘. 특히 여러 세션에 걸쳐 재사용되는 종목코드는 주기적으로 재검증이 필요함.

### 4-5) 데이터 소스별 특성에 따라 서로 다른 기술적 함정이 존재

| 소스 유형 | 함정 |
|---|---|
| flow (순매수, 공매도) | 장 마감 후 발표 → 1일 shift 필수 |
| stock (외국인보유율) | 누적 레벨이라 짧은 rolling window로는 변동성 부족 |
| 캘린더 기반 (환율) | 거래소 캘린더 불일치로 인한 룩어헤드 |
| 이벤트 기반 (DART) | 장중 발표 가능 + 이벤트 희소성 → recency feature 설계 필요 |
| 재무 기준 (밸류에이션) | 1일 shift 불필요하나 중장기(h=20) horizon에서만 강하게 작동 |

## 5. 최종 모델 방향에 대한 시사점 (결정 보류 중)

지금까지의 증거를 종합하면:

- **단일 공통 feature 조합**을 모든 종목에 강제하는 방식은 데이터로 뒷받침되지 않음 (대한제강 반례)
- 가장 신뢰할 수 있는 후보는 **밸류에이션(h=20)** — 5종목 중 3종목에서 국면 조정 후에도 Buy&Hold 상회
- 수급(flow) feature는 저유동성 종목에서 일관되게 BASE 대비 개선을 주지만 Buy&Hold까지는 못 이김
- FX/외국인보유율/DART 계열은 현재까지 실전 배포 후보에서 제외하는 것이 타당해 보임

**남은 결정 사항**: 종목별 커스텀 조합 vs 단일 조합 여부, 몇 개 종목까지 포트폴리오에 포함할지, 실거래 전환 시 threshold/포지션 사이징 정책 — 다음 논의에서 확정 필요.

---

## 6. 향후 과제

- 매수/매도 방향을 구분한 DART 대량보유 재시도 (공시 원문 파싱)
- 아직 다루지 않은 재료: 신용거래(융자잔고), 관세청 수출입 무역통계, 네이버 검색량 트렌드, 섹터 스필오버
- 밸류에이션 h=20 신호를 다른 저유동성 종목으로 추가 교차검증
- 종목별 최적 threshold 스윕 (지금까지 0.55 고정으로만 검증)
- 포지션 사이징/자금관리 규칙 도입 검토 (현재는 전액 순차 진입만 검증)
- 최종 모델을 한전기술/대한제강 등 다른 검증된 종목으로 확장

| Horizon | 20일 |
| 선정 근거 | 2025년 국면 제외해도 재현됨 (BASE -5.0% / COMBINED 64.1% / Buy&Hold 29.5%), 5종목 중 가장 탄탄한 근거 |
| 산출물 | `train_final_model.py`, `final_model_064350_h20.joblib`, `final_model_064350_h20_metadata.json` |

### 설계 특징

- 지금까지의 walk-forward 검증용 스크립트와 달리, **전체 히스토리로 1회 최종 학습**하여 배포용
  아티팩트(joblib)로 저장
- 메타데이터 JSON에 학습 시점 성능 참고값, feature 목록, 하이퍼파라미터를 같이 기록해 "모델 카드" 역할
- `predict_latest()`로 최신 시점 예측 지원

### 발견한 버그와 수정

`build_feature_dataset()`의 마지막 `dropna()`가 `label`/`future_return` 컬럼까지 포함해서,
라벨이 구조적으로 NaN인 최근 20영업일(horizon만큼)이 통째로 잘려나가는 문제를 발견. 학습 시엔
문제없지만 "오늘 시점 예측"에는 결정적 결함. `add_label()`을 건너뛰고 개별 feature 함수만
호출하는 방식으로 우회 -- 향후 다른 종목 확장 시에도 동일하게 적용 필요.

### Feature Importance (전체 데이터 재학습 기준)

상위 항목이 전부 밸류에이션 계열로 나옴 (`div` 1위, `per` 2위, `per_zscore_252d`/`pbr`/`pbr_zscore_252d`도
상위 8개 안에 포함) -- ablation에서 COMBINED가 BASE를 이겼던 이유가 실제로 밸류에이션 feature의
기여라는 걸 재확인하는 sanity check 역할을 함.

### 실전 검증 사례 (2026년 8월)

모델이 예측 확률 0.0956(base rate ~0.48 대비 극단적으로 낮음)을 출력. 원인을 추적한 결과:

1. 7/24 2분기 어닝쇼크 발표 (영업이익 컨센서스 대비 -14%, 전년 대비 -9.8%)
2. 증권사 목표주가 일제히 하향 → 7/27 하루 -16.14% 폭락, 52주 신저가
3. 같은 주 코스피 전체 폭락 (7/28 -10.84%, 7/29 -5.98%)과 겹침
4. 이후 일부 반등했으나 20일 수익률은 여전히 마이너스인 불안정한 국면

처음엔 일별 변동폭(±8~11%)이 비정상적으로 보여 데이터 글리치를 의심했으나, yfinance
`auto_adjust=False` raw 데이터와 외부 소스(증권사 리포트, 뉴스)를 교차검증한 결과 실제 시장
이벤트로 확인됨. **모델이 이 불안정한 국면을 정확히 포착해서 신중한(베어리시) 신호를 낸 것으로
해석** -- 극단적인 예측이 나왔을 때 곧바로 모델 결함으로 의심하기보다 실제 시장 상황부터
교차검증해야 한다는 실무적 교훈을 남김.

### 한계 (재확인)

- Buy & Hold 대비 절대 우위를 보장하지 않음 (BASE보다 낫다는 상대적 우위만 검증됨)
- Walk-forward 검증 당시 AUC가 미래에도 재현된다는 보장 없음
- horizon=20이라 신호 빈도가 낮음 -- 단기 트레이딩이 아니라 몇 주 단위 포지션 전략에 적합

## 8. 비지도학습 기반 국면 이례성 검증 (quant_unsupervised)

**배경**: 2-3절(밸류에이션)에서 백테스트 수익이 특정 연도에 집중되는 현상을 발견했으나,
지금까지는 "그 연도가 통계적으로 실제 이례적인 국면이었는지"를 정량적으로 확인하지 않고
연도별 log-return 기여도 비중(50% 초과 시 국면 의존적으로 판정)만으로 판단해왔음.

별도 레포(`quant_unsupervised`)에서 **라벨을 전혀 쓰지 않는 비지도 클러스터링**으로 이 질문에
직접 답하기 위한 검증을 진행함. 방법론은 다음과 같음:

- 변동성/모멘텀 피처(`hist_vol_20d`, `return_20d`, `bb_width`, `macd_hist`) 4개만 사용
- K-means, K=2~6 중 silhouette score로 최적 K 자동 선택
- 연도별로 각 국면이 차지한 거래일 비중을 집계
- 집중 연도의 국면 구성이 다른 연도 평균과 얼마나 다른지, **절대 차이(%p)**와 **배율(倍)** 두 기준으로 이례성 판정
  (절대 차이만 쓰면 "평소 4% → 특정 연도 30%"처럼 비중이 작은 국면이 폭증하는 경우를 놓칠 수 있어 배율 기준을 추가함)
- 거래일 수가 비정상적으로 적은 연도(분석 시점 기준 진행 중인 당해 연도 등)는 baseline 계산에서 자동 제외

### 검증 결과

| 종목 | 집중 연도 | 지배 국면 프로필 | 절대 차이 | 배율 | 판정 |
|---|---|---|---|---|---|
| 모트렉스 (118990) | 2020 | 고변동성(vol 1.36) + 급등 모멘텀(+27.4%) | 0.267 | **7.76배** | 이례적 |
| 한전기술 (052690) | 2021 | 고변동성(vol 0.92) + 급등 모멘텀(+30.7%), 2026년 제외 후 재계산 | 0.282 | **5.08배** | 이례적 |

두 종목 모두 K=2로 수렴했고, 국면 1은 일관되게 "고변동성 + 강한 상승 모멘텀" 프로필로 나타남
(코로나 반등장, 급등 랠리 등과 시기적으로 겹치는 것으로 추정).

### 결론

밸류에이션 백테스트 수익 집중 현상이 **우연한 연도 편중이 아니라 통계적으로 확인 가능한 이례적
시장 국면과 실제로 맞물려 있음**이 라벨을 전혀 쓰지 않은 독립적인 방법론으로 재확인됨. 이는
4-1절의 "국면 집중형" 실패 유형 분류를 뒷받침하는 정량적 근거를 추가하는 결과이며,
**"밸류에이션 edge는 평시에 꾸준히 작동하는 신호라기보다, 특정 고변동성/급반등 국면에서
두드러지는 신호"**라는 해석에 더 무게를 실어줌.

### 한계 및 향후 과제

- 지금까지 모트렉스/한전기술 2종목만 검증. 대한제강(2020년 79.5% 집중)도 동일 방법으로 교차검증 필요
- 국면 이례성 판정 threshold(절대 차이 30%p, 배율 3배)는 임의로 정한 값 -- 더 많은 종목/연도로 민감도 분석 필요
- 국면 정의에 쓰인 피처(변동성/모멘텀 4개)가 밸류에이션 feature와 얼마나 독립적인지는 아직 미검증
  (다음 단계로 PCA를 통해 alternative feature가 실제로 새로운 정보 축을 만드는지 확인 예정)
- K-means는 원형(spherical) 클러스터를 가정함 -- Gaussian Mixture 등으로 교차검증하면 더 견고해질 수 있음

## 9. Triple-barrier / Meta-labeling 실험 (라벨 재정의)

**배경**: `quant_ranking_kr`/`quant_sector_rotation`까지 문제 설정을 계속 바꿔봤지만
전부 실패. 공통 실패 패턴("AUC/edge는 잡히는데 백테스트/국면 검증에서 무너진다")이
라벨 정의 자체("N일 후 방향 이진분류")의 문제일 수 있다는 가설로 `quant_xgboost`에
triple-barrier 라벨링(López de Prado 방식) + meta-labeling을 순서대로 검증.

### 결과 요약

| 실험 | 설정 | 백테스트 최종 판정 |
|---|---|---|
| Triple-barrier 직접분류 | 대한제강, BASE/COMBINED, pt_sl=(2,1) | **실패** (거래비용/구조적 저하) |
| Meta-labeling | 대한제강 | **실패** (표본 확대 시 0/5로 붕괴) |
| Triple-barrier 직접분류 | 현대로템, COMBINED, pt_sl=(2,1), num_days=20, th=0.65 | 개별 검증 4/5 (전체기간), 5/5 (2025 이전 절단) |
| Meta-labeling | 현대로템 | **실패** (Buy&Hold가 너무 강함) |
| Triple-barrier 직접분류 | 한전기술, 동일 설정 | 개별 검증 4/5 (전체기간), 4/5 (2025 이전 절단) |
| **Triple-barrier 직접분류 (풀링)** | **현대로템+한전기술 동일가중 블렌딩, 동일 설정 그대로 유지, 거래 수 178~188건** | **5/5 -- 최종 통과** |

### 검증 여정 (중요한 방법론적 교훈)

1. 현대로템 단독으로 처음 5-seed(4/5) + 2025년 이전 절단(5/5)까지 전부 통과 → "이 프로젝트
   최초의 성공 후보"로 보였음
2. 거래 수가 77~113건으로 적어 의심 → `num_days`를 20에서 10으로 줄여 회전율을
   높이는 방식으로 "표본 확대 stress test"를 시도 → 전체기간 0/5, 2025 이전 2/5로 완전
   붕괴 → 처음엔 "소표본 우연이었다"고 결론 내림
3. **사용자 피드백으로 이 결론이 틀렸을 수 있음을 재확인**: `num_days`를 바꾸면 배리어
   폭(`daily_vol × √num_days`)도 같이 바뀌어서 사실상 **다른 전략**이 됨 -- "표본을
   늘렸다"가 아니라 "전략을 바꿨다"였음. 다만 같은 num_days=20에서 시드만 바꿔도
   687%~1512%로 크게 흔들렸던 것 자체는 여전히 유효한 불안 신호였음
4. **올바른 재검증**: `num_days=20`(전략 원본)은 그대로 두고, 세 번째 종목(한전기술,
   현대로템과 같은 저유동성 대기업 계열)에 동일 전략을 그대로 적용 → 개별로도 4/5 통과
5. **최종 확인**: 두 종목(현대로템+한전기술)의 개별 백테스트 결과를 동일가중으로 사후
   블렌딩(모델/feature/라벨은 종목별로 완전히 독립적으로 학습, 결과만 포트폴리오처럼
   섞음) → 거래 수 178~188건 확보, **5-seed 전부 Buy & Hold를 이김**, 마진도 개별
   검증 때보다 더 여유 있음

### 핵심 발견

1. **"표본을 늘려서 재검증한다"는 원칙 자체는 옳았지만, 표본을 늘리는 방법이 전략을
   훼손하면 안 됨** -- `num_days`처럼 라벨 정의에 관여하는 파라미터를 바꿔서 표본을
   늘리면 그건 재검증이 아니라 다른 실험임. 올바른 방법은 (a) 전략은 고정한 채 (b)
   독립적인 다른 종목/기간을 추가해서 관측치를 늘리는 것.
2. **밸류에이션(PER/PBR z-score) 결합이 세 종목(대한제강/현대로템/한전기술) 모두에서
   AUC를 일관되게 개선시킴** -- feature 자체의 유효성은 이 프로젝트 전체에서 가장
   반복적으로 확인된 사실. 다만 대한제강만 최종 백테스트에서 실패함 (거래비용, 구조적
   저하) -- 종목 특성(유동성, 밸류에이션 신호 강도)에 따라 최종 성패가 갈릴 수 있음.
3. **국면 집중 우려는 두 종목의 최대 기여 연도가 다름(현대로템 2025년 vs 한전기술
   2021년)으로 상당 부분 해소됨** -- 특정 한 해의 시장 국면 하나에 이 결과 전체가
   기대고 있는 게 아니라는 근거.
4. **Buy & Hold 국면 제외 검증 시 "행 삭제"가 아니라 "기간 절단"을 써야 함** (행을
   지워도 Buy & Hold는 실제 가격 이력을 그대로 반영하므로 불공정 비교가 됨) -- 세션
   중 한 번 실수했다가 발견하고 수정.

### 결론

**Triple-barrier 라벨링(1:2 손익비, num_days=20) + BASE+VALUATION COMBINED feature +
threshold=0.65 조합이, 현대로템(064350)과 한전기술(052690) 두 종목을 동일가중
블렌딩한 포트폴리오 기준으로 5개 시드 전부 거래비용 반영 후 Buy & Hold를 이김.**
이 프로젝트(quant_xgboost/lightgbm/ranking_kr/sector_rotation/meta-labeling 전체
포함) 최초로 모든 검증 관문(AUC 5-seed, 백테스트 5-seed, 국면 절단 재검증, 독립
종목 재현성, 풀링 표본 확대)을 통과한 결과.

**남은 한계**: (1) 두 종목 다 저유동성 대기업 계열이라는 공통 특성이 있어 이 결과가
그 카테고리에 국한될 가능성, (2) 여전히 거래 수가 200건에 살짝 못 미침, (3) 대한제강
에서는 같은 설정이 실패했으므로 "모든 종목에 통하는 전략"이 아니라 "특정 프로필의
종목에 통하는 전략"으로 이해해야 함.

### 다음 단계 후보

- **이 조합을 production 후보로 격상**: `train_final_model.py` 패턴을 따라
  현대로템+한전기술 풀링 모델을 실제 프로덕션 후보로 문서화
- **저유동성 대기업 계열 종목 유니버스 확장**: 같은 프로필(대기업 계열, 저유동성)의
  다른 종목(예: 모트렉스 등)으로 유니버스를 넓혀 거래 수를 200건 이상으로 자연스럽게
  확보하면서 재현성 계속 확인
- **검증 방법론 강화는 여전히 유효한 다음 과제**: 이번에 우연히 방법론 실수(전략 변경을
  표본 확대로 착각)를 사용자 피드백으로 바로잡을 수 있었지만, 앞으로는 PBO/Deflated
  Sharpe Ratio 같은 통계적 도구로 이런 실수를 사전에 방지할 필요가 있음

### [최종 갱신 2026-08] PBO 검증 이후 배포 부적합 판정

위 결론(현대로템+한전기술+모트렉스 풀링, 5/5 통과)이 나온 뒤, PBO(Probability of
Backtest Overfitting) 3종 검증을 추가로 진행함:

| 축 | PBO | 판정 |
|---|---|---|
| threshold만 | 6.7% | 낮음 |
| threshold × 종목조합 | 81.3% | 매우 높음 |
| pt_sl (이 세션에서 실제 탐색했던 축) | **95.6%** | **거의 최악** |

pt_sl 축 검증 결과, 채택했던 pt_sl=(2,1)은 구간별 in-sample 최고 빈도에서
5개 후보 중 4위(25/252회)에 그쳤고, 세션 초반 AUC 완전 랜덤으로 이미 폐기했던
pt_sl=(1,1)이 오히려 가장 자주(97/252회) 1등으로 뽑힘. 이는 5-seed/국면검증/
체결타이밍/청산판정 개선을 전부 통과했더라도, "그 설정 자체를 결과를 보고
탐색해서 골랐다"는 사실을 이 검증들 중 어느 것도 잡아내지 못했다는 뜻.

## 추가 실험: pt_sl 사전등록 재검증 (calendar-day 버그 수정 반영)

### 배경
이전 [배포 부적합] 판정(PBO 95.6%)의 원인이었던 pt_sl 사후선택 문제를 해결하기
위해 pt_sl=(2,1)을 사전등록하고, 동시에 get_vertical_barrier()의 calendar-day
버그(실제 보유기간이 20 거래일이 아니라 13~14 거래일이었던 문제)도 수정해서
3종목 풀링 5-seed 재검증.

### 결과
5개 시드 중 3/5만 Buy&Hold를 이김 (기준: 4~5/5 필요) -- 기준 미달.
버그 수정 전(동일 설정, calendar-day 버그 있는 상태)에는 5/5 통과했었고
거래 수도 255~259건 -> 206~216건으로 줄어듦. 이전의 "5-seed 통과"가
부분적으로 calendar-day 버그(실제보다 짧은 보유기간, 더 많은 거래 수)
자체의 산물이었을 가능성을 시사함.

052690(한전기술) 개별 결과가 특히 취약함 (seed=42 기준 net 4.3% vs
Buy&Hold 698.2%) -- 블렌딩 실패의 주요 원인으로 보임.

### 결론
[실패]. 실패 원인은 pt_sl 자체가 아니라 calendar-day 버그 수정(실제 보유기간
13~14일 -> 20일)임 -- pt_sl=(2,1)은 지난번과 동일한 값을 그대로 사전등록해서
썼고, 이번 재검증의 의의는 "값을 바꾸지 않고도(탐색 없이) 결과가 재현되는가"를
정직하게 테스트한 것. 답은 "재현 안 됨"이었고, 원인은 버그 수정으로 보임.

**052690을 제외하고 재검증하지 않음** -- "성과가 나쁜 종목을 사후에 빼는 것"도
threshold×종목조합 축 PBO(81.3%, 지난 판정 기준)가 경고한 것과 같은 종류의
탐색이므로, 결과를 본 뒤 종목 구성을 바꾸는 시도 자체를 하지 않기로 함.

### 남는 질문 (다음 실험 후보로만 사용, 이번 판정엔 영향 없음)
한전기술이 calendar-day 버그 수정에 유독 민감했던 이유는 미상 -- 유동성/변동성
특성 차이 가설은 있으나 검증 안 함.

### 교훈
5-seed/국면검증 같은 "일관성" 기준을 통과했다고 해서 그게 방법론 버그와
무관하다는 뜻은 아님 -- 이번처럼 라벨링 버그 하나를 고쳤을 뿐인데 5/5가 3/5로
무너질 수 있다는 건, 과거의 모든 [통과] 판정도 잠재적으로 유사한 구현 버그에
기댔을 가능성을 열어둬야 한다는 뜻.
